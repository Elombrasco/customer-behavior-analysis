Ce que l'analyse montre (sur l'ensemble des données)

  • Le panier moyen est stable, autour de 60 $, quel que soit le genre, l'âge, l'abonnement ou le mode de livraison. La croissance vient du nombre d'achats, pas du montant par achat.
  • Les hommes génèrent 68 % du chiffre d'affaires parce qu'ils représentent 68 % des achats, pas parce qu'ils dépensent plus.
  • Les abonnés (27 % des clients) ne dépensent pas plus par achat : 59,49 $ contre 59,87 $.
  • Les vêtements et les accessoires apportent environ 77 % du chiffre d'affaires. 43 % des achats utilisent une remise.
  • Limites : pas de dates dans les données, donc pas d'analyse de tendance. Les 37 notes manquantes ont été remplacées par la médiane de leur catégorie.
Données : customer_shopping_behavior.csv (3 900 achats). Ce tableau de bord web reprend les indicateurs de la version Power BI. Code, requêtes SQL et rapport : GitHub Elombrasco.
